# EaseMuse — Project files

This directory (`.build/`) is managed by [Interactor](https://interactor.com).

| File / folder | Purpose |
|---|---|
| `project.yaml` | Project metadata (name, status, dates) |
| `vision.md` | Long-form product vision — the north star for this project |
| `phases/` | One file per phase |
| `tasks/` | One file per task |
| `sprints/` | One file per sprint |
| `CLAUDE.md` | Instructions for Claude Code |

**Editing files here** and committing will sync changes back to the Interactor web app automatically via webhook. Keep YAML frontmatter intact — it is the canonical source for field values.
